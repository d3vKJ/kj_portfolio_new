# Interview Me

## 이 스킬 사용법

"interview-me" 호출 시: 포트폴리오 프로젝트나 기술 스택에 대한 면접 질문을 던지고 답변 피드백 제공.

## 자주 나오는 질문 유형

### 프로젝트 설명
- "이 프로젝트에서 가장 어려웠던 부분은?"
- "이 기술을 선택한 이유는?"
- "다시 만든다면 뭘 다르게 하겠나?"

### 기술 심화
- "React의 렌더링 최적화 방법은?"
- "useEffect와 useLayoutEffect 차이는?"
- "SSR과 CSR의 차이와 선택 기준은?"

### 포트폴리오 공통
- "Next.js를 선택한 이유는?"
- "성능 최적화를 위해 무엇을 했나?"
- "접근성을 어떻게 고려했나?"

## 좋은 답변 구조 (STAR)

```
Situation: 어떤 상황이었나
Task: 무엇을 해야 했나
Action: 무엇을 했나 (기술적 결정 포함)
Result: 결과는 어떻게 됐나 (수치 있으면 최고)
```

## 답변 피드백 기준

- 구체적인가? ("최적화했다" → "이미지를 WebP로 변환하고 lazy loading 적용해 LCP 3.2s → 1.8s")
- 본인의 결정이 드러나는가?
- 배운 점이 포함되는가?

## 연습 방법

1. 프로젝트 코드/README 공유
2. "이 프로젝트로 면접 질문해줘"
3. 답변 → 피드백 반복

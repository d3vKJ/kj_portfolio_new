# Design Taste — Frontend

## "좋다"의 기준

1. **명확함** — 사용자가 다음에 뭘 해야 할지 1초 안에 안다
2. **일관성** — 같은 것은 같아 보인다. 간격·색·크기 패턴이 반복된다
3. **여백** — 빈 공간이 숨통을 준다. 꽉 채운 디자인은 항상 나쁘다
4. **계층** — 중요한 것이 먼저 눈에 들어온다

## 흔한 실수

- 텍스트 너무 작음 (본문 16px 미만)
- 색 대비 부족 (회색 위 연한 회색)
- 버튼이 버튼처럼 안 보임 (클릭 가능한지 불명확)
- 애니메이션 과다 — 움직임은 의미가 있을 때만
- 폰트 종류 3개 초과

## 포트폴리오 특이사항

- 첫 화면(above the fold)에서 "누구인지", "무엇을 하는지" 5초 안에 전달
- 프로젝트 썸네일: 가로세로 비율 통일, 배경 톤 일치
- CTA(연락하기/이력서 등) 위치: 헤더 또는 히어로 섹션에 노출

## 참조 기준

디자인 결정이 애매할 때: "신문처럼 읽히는가?" — 헤딩 → 부제 → 본문 순서로 정보가 흐르면 OK.

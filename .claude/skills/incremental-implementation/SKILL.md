# Incremental Implementation

## 원칙

항상 작동하는 상태를 유지하면서 기능을 추가한다.
"일단 완성하고 나서 정리" → X
"정리된 상태로 조금씩 확장" → O

## 구현 순서

```
하드코딩 → 변수화 → 동적화 → 최적화
```

**예시: 프로젝트 카드 목록**
1. HTML 하드코딩 1개 (스타일 집중)
2. 데이터 배열로 분리 + map 렌더링
3. 외부 파일(JSON/ts) 로 데이터 이동
4. 로딩/에러 상태 추가
5. 애니메이션

각 단계에서 브라우저 확인 후 다음으로.

## 커밋 전략

각 단계가 완료될 때마다 커밋. 단계 경계가 커밋 경계.

## 막힐 때

지금 만들려는 게 너무 크면: "이것의 가장 단순한 버전은?" 을 물어보고 그것부터 시작.

## 포트폴리오에 적용

전체 사이트를 한 번에 만들려 하지 말 것:
1. 텍스트만 있는 한 페이지 배포
2. 섹션 하나씩 추가
3. 각 섹션 polish
4. 인터랙션/애니메이션 마지막에
